# React Native Viva Questions and Answers

## 3. Which command do we enter to create a React Native application?

**React Native CLI**

``` bash
npx @react-native-community/cli init MyApp
```

**Expo**

``` bash
npx create-expo-app MyApp
```

Move into the project:

``` bash
cd MyApp
```

## 4. What is the purpose of the `android` folder?

The `android` folder contains all native Android project files required
to build and run the app, including Gradle files, AndroidManifest.xml,
Java/Kotlin code, and resources.

## 5. Why is the `ios` folder in the folder structure?

The `ios` folder contains native iOS project files such as the Xcode
project, Swift/Objective-C code, Info.plist, and app resources. It is
used to build and run the app on iOS devices.

## 6. Which file presents the main screen?

Usually `App.js` or `App.tsx`. It is the root component where the
application's UI starts.
      
## 7. Difference between `package.json` and `package-lock.json`

  -----------------------------------------------------------------------
  package.json                        package-lock.json
  ----------------------------------- -----------------------------------
  Contains project information and    Stores the exact installed
  dependency list.                    dependency versions.

  Can be edited manually.             Automatically generated by npm.

  Defines required packages.          Ensures consistent installations.
  -----------------------------------------------------------------------

## 8. What is the use of the `node_modules` folder?

It stores all installed npm packages and libraries used by the project.
It is created automatically after running:

``` bash
npm install
```

## 9. Which file is the entry file of your application?

The entry file is `index.js`.

Example:

``` javascript
import { AppRegistry } from 'react-native';
import App from './App';
import { name as appName } from './app.json';

AppRegistry.registerComponent(appName, () => App);
```

## 10. What is Metro Bundler? What is its use?

Metro Bundler is React Native's JavaScript bundler. It bundles
JavaScript files, supports Fast Refresh, watches file changes, and
serves the JavaScript bundle.

Start Metro:

``` bash
npx react-native start
```

## 11. Which command is needed to run the application on Android?

Start Metro:

``` bash
npx react-native start
```

Run the app:

``` bash
npx react-native run-android
```

## 12. How do you verify that a physical device is connected?

Run:

``` bash
adb devices
```

If your device appears with the status `device`, it is connected
successfully.

## 13. Purpose of USB Debugging

USB Debugging allows communication between an Android device and Android
Studio/ADB. It is used to install apps, debug, view logs, run ADB
commands, and test on a real device.

## 14. How do you test on an emulator and physical device?

### Emulator

1.  Open Android Studio and start the emulator.
2.  Run:

``` bash
npx react-native start
npx react-native run-android
```

### Physical Device

1.  Enable Developer Options and USB Debugging.
2.  Connect the device via USB.
3.  Verify:

``` bash
adb devices
```

4.  Run:

``` bash
npx react-native start
npx react-native run-android
```
